# HTML 汇总页（视频总结.html）

## 何时生成

每当 `output/` 目录新增或更新任何 `*_总结.md`（单视频 `register` 后、多视频批次全部结束后），必须重建汇总页：

```bash
python3 "$SKILL_DIR/scripts/summarize_pipeline.py" finalize --dir "工作目录"
# 等价于 build_html.py；若索引可疑可加 --rebuild-index
```

`--dir` 是包含 `output/` 子目录的工作目录（通常为当前目录）。输出 JSON 含 `html.status`、`html.html`、`html.docs`、`html.server_running`、`html.url`、`html.bili_bridge`（油猴桥接脚本的本地 URL）。生成物固定为 `工作目录/视频总结.html`，直接覆盖旧文件，无需询问用户。还会自动确保本地后台服务 `scripts/serve.py`（静态托管 + 删除 API；删除时同步 `output/.index.json`；每个目录一个确定性端口 18900–18999，仅监听 127.0.0.1）在运行，并自动替换旧版纯静态服务；`server_running` 为 false 时如实告知用户播放器暂不可用。

## 页面能力（告知用户即可，不要重复实现）

- 左侧导航列出 `output/` 全部总结（按文件修改时间倒序），点击切换文章。
- 右侧正文区顶部有「总结 / 原文」两个 tab（与播放器一起吸顶，滚动时也可切换）：总结即渲染后的 Markdown 正文（自动隐藏「原文字幕」「中文字幕」小节，但保留并展示文末「运行统计」）；原文按 SRT 逐条展示，每条带可点击时间戳（http 模式下同样让播放器跳转播放）。Markdown 没有「## 原文字幕」小节时「原文」tab 置灰。切换文章时若新文章无原文，自动回到总结视图。
- 原文 tab 中，若 Markdown 含「## 中文字幕」小节（非中文视频的平台中文字幕轨，或经用户同意的 LLM 逐条翻译），tab 栏右侧出现「显示翻译」按钮：点击后每行原文下方显示对应中文，再点隐藏；开关状态记忆在 localStorage。中文与原文条数一致时按序号对齐，不一致时按最近时间戳（±2.5 秒）匹配。无该小节（中文视频或无中文来源）时按钮不出现。
- 顶部内嵌播放器：YouTube embed / Bilibili player / Apple Podcasts embed；小红书与小宇宙无稳定内嵌时隐藏 iframe 并显示提示，时间戳在新标签页打开原链。切换文章自动载入；YouTube/B 站/Apple 的时间戳点击会让播放器跳到该秒并自动播放。
- 播放时总结/原文视图自动跟随进度：当前分段（总结视图按段落标题时间戳）或当前字幕行高亮并平滑滚动——总结分段滚到吸顶栏下方顶部，字幕行滚到第二行（上一行保留在顶部作上下文）；用户手动滚动后暂停跟随 5 秒。原文字幕解析保留毫秒，高亮按 `cue.start <= playTime` 匹配（不加提前量），避免比画面快约 1 秒。
- 跟随的进度来源分平台：YouTube 走 iframe postMessage 协议，精确跟随。Bilibili 外链播放器无进度接口，采用双模式：默认在点击时间戳跳转播放后用本地时钟估算（tab 栏右侧显示「估算跟随 · 点时间戳校准」，播放器内暂停/拖动/倍速会失准，再点任意时间戳即校准）；安装油猴脚本 `bili_bridge.user.js` 后自动切换为精确跟随（脚本随每次重建复制到工作目录，装法：浏览器装 Tampermonkey 后打开脚本输出的 `bili_bridge` URL 即弹出安装）。
- 右上角「隐藏播放器」按钮可折叠播放器，状态记忆在 localStorage。
- http 打开时每个导航项悬停出现「✕」删除按钮，点击即删（无确认）：把对应 Markdown 移入 `output/.trash/`（带时间戳前缀，可找回）并自动重建 HTML 快照；file:// 快照模式下不提供删除。`.trash` 目录不参与汇总，用户要求彻底清理时才删它。
- 双击 HTML（file://）打开时，页面检测到本地服务在运行会**自动跳转**到 `http://127.0.0.1:端口/视频总结.html`，播放器与实时更新直接可用；交付时把该 URL 一并告知用户。YouTube 要求嵌入页面带 Referer，file:// 页面无 Referer 会报 Error 153，这是平台限制。
- 后台服务重启电脑后失效（不安装任何常驻项）；此时双击 HTML 仍可正常阅读，页面显示黄色提示、时间戳退回新标签页打开原视频，重新运行一次本 skill（或提示里的一行命令）即恢复。
- http 打开即为**实时模式**：每 30 秒自动拉取 `output/` 目录，新总结无需重新生成 HTML 即可出现。

## 约束

- Markdown 渲染由页面内置 JS 完成，只覆盖总结文档使用的语法子集；不要往总结里引入表格、图片等额外语法后指望汇总页正确渲染。
- 播放器 iframe 需要联网；地区受限或不允许嵌入的视频，iframe 内会显示平台自身的错误提示，属正常现象。
- 时间戳跳转只对「当前打开文章对应的视频」生效；指向其他视频的链接仍按普通外链在新标签页打开。
